# bintyty332.github.io

A simple personal webpage.

Once GitHub Pages is turned on, the site lives at:

**https://bintyty332.github.io**

## Turn on GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Branch: **main**. Folder: **/ (root)**.
4. Save. The site usually appears within a minute or two.

Edit `index.html` and commit. The page updates on the next Pages build.
